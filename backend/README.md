# Backend

O coração do Clipador: pipeline de processamento, banco de dados (SQLite), fila de
tarefas retomável, modo demo e a linha de comando (`clipador ...`).

- Código: `src/clipador/`
- Testes: `tests/`
- Usa as `integracoes/` para falar com YouTube, TikTok e LoL, mas nunca lê as chaves.

Veja o [README principal](../README.md) para instalar e rodar.
